# SHADI SMP Website

وب‌سایت رسمی سرور Minecraft به زبان فارسی.

## تغییر آدرس سرور
فایل server.json را باز کن و مقدار address را تغییر بده؛ سپس تغییرات را Commit کن. سایت آدرس جدید را از همین فایل می‌خواند و دکمه کپی را فعال می‌کند.

نمونه:
{
  "address": "play.example.net:25565",
  "version": "Paper 26.2"
}

## انتشار رایگان با GitHub Pages
سایت از شاخه main و پوشه ریشه (/) منتشر می‌شود.

## تکمیل محتوا
قوانین دقیق، رنک‌ها، قیمت‌های شارد و تصاویر واقعی سرور هنوز باید با اطلاعات تأییدشده تکمیل شوند؛ در نسخه فعلی برای این موارد متن جایگزین گذاشته شده است.
