# SHADI SMP Website

وب‌سایت فارسی و راست‌چین سرور Minecraft با طراحی واکنش‌گرا.

## فایل‌ها
- `index.html`: ساختار و محتوای سایت
- `style.css`: فایل سبک پایه
- `site-features.css`: ظاهر Feedback
- `mobile-fixes.css`: چیدمان تبلت و موبایل و دکمه‌های ناوبری
- `script.js`: منو، کپی آدرس، ناوبری درون‌صفحه و ارسال Feedback
- `server.json`: آدرس و نسخهٔ سرور
- `auth-config.js`: تنظیمات عمومی Supabase برای Feedback ناشناس

## قابلیت‌های سایت
- نمایش اطلاعات SHADI SMP و آدرس اتصال
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل
- ارسال Feedback بدون نیاز به ساخت حساب کاربری
- ناوبری قبلی/بعدی بین بخش‌ها و بازگشت به بالای صفحه

برای فعال‌کردن ارسال Feedback، راهنمای `SUPABASE_SETUP.md` را بخوان.
