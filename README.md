# SHADI SMP Website

وب‌سایت فارسی و راست‌چین سرور Minecraft با طراحی واکنش‌گرا.

## فایل‌ها
- index.html: ساختار و محتوای سایت
- style.css: طراحی، رنگ‌بندی و نسخه موبایل
- script.js: منوی موبایل و کپی آدرس سرور
- server.json: تنظیمات اتصال سرور

## تغییر IP سرور
برای تغییر آدرس اتصال، مقدار address را در فایل server.json تغییر بده و تغییر را روی شاخه main ثبت کن. نمونه:

{
  "address": "YOUR-SERVER-IP:25565",
  "version": "Paper 26.2"
}

در حال حاضر آدرس عمداً خالی است تا IP تأییدشده وارد شود.

## رنک‌ها
- PRO: فقط برای نفرات اول تا سوم لیدربورد رسمی.
- ADMIN: فقط برای اعضای رسمی تیم مدیریت سرور.
- OWNER: فقط برای سازنده‌ی SHADI SMP.

## انتشار
سایت با GitHub Pages و از شاخه main در مسیر اصلی مخزن منتشر می‌شود.
