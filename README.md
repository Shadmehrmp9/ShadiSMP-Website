# SHADI SMP Website

وب‌سایت فارسی و راست‌چین سرور Minecraft با طراحی واکنش‌گرا.

## امکانات
- نمایش اطلاعات SHADI SMP و آدرس اتصال
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل
- دیوار Feedback عمومی با نام بازیکن و نمایش پیام‌ها
- پاسخ مدیر زیر هر پیام و حذف امن از Supabase Dashboard
- ناوبری قبلی/بعدی بین بخش‌ها و بازگشت به بالای صفحه

## فایل‌های اصلی
- `index.html`: ساختار و محتوای سایت
- `site-features.css`: ظاهر Feedback و دیوار پیام‌ها
- `mobile-fixes.css`: چیدمان تبلت و موبایل و دکمه‌های ناوبری
- `script.js`: منو، کپی آدرس، ناوبری و Feedback
- `server.json`: آدرس و نسخهٔ سرور
- `auth-config.js`: تنظیمات عمومی Supabase

برای فعال‌کردن دیوار Feedback و مدیریت پاسخ‌ها، راهنمای `SUPABASE_SETUP.md` را بخوان.
